## 📌 Ключові можливості

1. **Актуарна математична модель Гомпертца-Мейкхема**:
   $$\mu(x) = \alpha e^{\beta x} + \gamma$$
   - $\alpha \approx 0.0001$ — фоновий темп смертності.
   - $\beta \approx 0.0815$ — експоненціальний темп старіння (смертність подвоюється кожні ~7.8 років).
   - $\gamma \approx 0.0006$ — постійна стохастичних зовнішніх ризиків.
   - Модифікатори способу життя виступають мультиплікаторами відносного ризику ($HR$).

2. **🩻 Інтерактивний анатомічний біосканер тіла (Body Scanner Telemetry)**:
   - Векторний SVG-силует із лазерною анімацією сканування та живими пульсуючими вузлами органів.
   - **6 ключових фізіологічних вузлів**:
     - 🧠 **Головний мозок та ЦНС** (сон, глімфатичний кліренс, дистрес, етанол).
     - 🫀 **Серцево-судинна система** (артеріальний тиск, пульс спокою, кардіореспіраторна витривалість VO2 Max).
     - 🫁 **Легені та дихальний тракт** (куріння тютюну, тверді дисперсні частки PM2.5).
     - 🥩 **Печінка та метаболічний профіль** (рафінований цукор, інсулінорезистентність, фастинг/аутофагія, ІМТ).
     - 🧬 **Геном та клітинні теломери** (спадкове довголіття батьків, теломери, стать, вік).
     - 🛡️ **Імунна система та соціальна інтеграція** (програма CTRA, рівень кортизолу, окситоциновий буфер).
   - **Оновлення в реальному часі**: під час проходження тесту кожен орган забарвлюється у зелений (захищений стан), червоний (підвищене навантаження) або ціановий (базовий стан).
   - При кліку на будь-який орган відкривається детальна картка з точним переліком плюсів та мінусів від ваших виборів і прямими посиланнями на наукові дослідження.
   - Доступний як у процесі тесту (зручний висувний Live-модуль), так і у фінальному звіті для повного аудиту.

3. **100% Доказова база (Open Access / PubMed)**:
   - До **кожного запитання** додано пояснення точного біологічного механізму старіння та прямі посилання на повнотекстові рецензовані публікації в журналах: *The Lancet, JAMA, BMJ, New England Journal of Medicine, Circulation, PNAS, Nature Aging*.

4. **Розширена візуалізація та факторний аналіз**:
   - Інтерактивна **крива ймовірності дожиття** за роками (Chart.js).
   - 7-осьовий **радар фізіологічної стійкості систем організму** (шкала 0-100).
   - Топ-5 захисних факторів та Топ-5 факторів ризику.
   - **Карта оптимізації**: персоналізовані кроки, які повертають найбільшу кількість втрачених років.

## 🛠️ Стек технологій

- **HTML5 & Vanilla CSS**: Кастомна дизайн-система без громіздких фреймворків, глибока темна тема актуарної телеметрії (`#0b0f19`), мікроанімації, glassmorphism, повна адаптивність (mobile / tablet / desktop).
- **Чистий Vanilla JavaScript (ES6+)**: Відсутність зовнішніх важких залежностей, миттєве завантаження (<0.3s), безпека даних (жодна інформація не зберігається на сервері).
- **SVG / Vector Graphics**: Інтерактивні анатомічні шари та жива пульсуюча анімація.
- **Chart.js 4.4**: Апаратне прискорення рендерингу кривих та радарів.

## 🚀 Локальний запуск

Оскільки проєкт використовує чистий веб-стек, його можна запустити будь-яким статичним HTTP-сервером:

```bash
# Клонувати репозиторій
git clone https://github.com/Ru1zy/mortality-estimator.git
cd mortality-estimator

# Запустити через будь-який зручний локальний сервер, наприклад:
npx serve .
# або
python -m http.server 8000
```

Відкрийте у браузері `http://localhost:8000`.

## 🔬 Наукові джерела (Select Evidence Base)

- **Framingham Heart Study**: Оцінка серцево-судинного ризику, ендотеліальної функції та пульсу спокою.
- **UK Biobank**: Когортні дослідження фізичної активності (VO2 max), сну та біомаркерів крові (>500,000 учасників).
- **Global Burden of Disease (The Lancet)**: Вплив тютюну, алкоголю, червоного м'яса та ультраоброблених продуктів.
- **WHO Global Health Observatory**: Популяційні актуарні таблиці дожиття та статевий диференціал.
